## Architecture

- Hilbert: sparse episode room addresses, no allocation for unused logical addresses.
- Euler/Bombelli: explicit 36-dimensional complex phasor and gauge-invariant relative phase features.
- Episodic AUX fingerprint: temporal source observation **linked** to an exact, typed record of situation, scene, context, object, source and ordering; the fingerprint is not a reversible substitute for the record.
- Corrections: preserve old and new sources with ordered, explicit correction edge; no rewriting past episodes.
- Recall: ambiguous semantic matches explicitly marked ambiguous; successful source-specific recall increases only a *semantic salience proxy*, not physical mass.
- Counterfactual: identical latest prompt, different stored history produces different reference route decisions. This is a local controlled demonstration, not claimed agent autonomy.
- PNAML11 integration: native `.pnv` and `.pna` draft contracts use existing operator classes (`SOURCE`, `IDENTITY`, `ORDER`, `COMPOSITION`, `ASSERT`, `EMIT`). Python is **only** an offline test reference; no Python transport is added to native PNAML.
