# PNCS KAKU v0.1

KAKU is the atomic semantic stroke of PNCS.

A KAKU is represented as:

    K = (v36, phase, mass, direction, polarity, role)

where:
- v36: exact 36D semantic vector,
- phase: optional phase binding; not fabricated when unavailable,
- mass: semantic mass scalar,
- direction: explicit relational direction,
- polarity: explicit signed/relational polarity,
- role: declared role in a composition.

KAKU alone does not need to correspond to a natural-language word.

A RADICAL is a validated graph of KAKU atoms and directed relations.

No natural-language keyword is canonical at L0.
