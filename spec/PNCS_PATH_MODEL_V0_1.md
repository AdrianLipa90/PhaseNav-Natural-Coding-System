# PNCS Path Model v0.1

A PNCS path is not merely a filesystem address.

A path is an ordered relational trajectory through canonical semantic-phase state.

Minimum path record:
- path_id
- level
- ordered node ids
- ordered relation ids
- source lineage
- target lineage
- basis_id
- status

Illustrative textual surface only:

    IF gravity BELOW 0.5 -> physics.gravity.low

The authoritative object is the resolved relational path graph beneath the text.
