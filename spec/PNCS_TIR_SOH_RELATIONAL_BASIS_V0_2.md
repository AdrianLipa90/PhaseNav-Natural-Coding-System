# PNCS TIR + Secret of a Half Relational Basis v0.2

Status: CANDIDATE / NATIVE_PNV_SEED / FAIL_CLOSED_CANON

## Purpose

This stage starts PNCS from two existing mathematical sources rather than from invented semantic axes:

- TIR / Metatime: binary distinction, information scale, phase/holonomy and relational action.
- The Secret of a Half v0.8: complement, unique half fixed point, projective boundary map, reciprocal inversion, self-duality and non-negative departure/defect.

The native executable representation is `native/PNCS_TIR_SOH_SEED_V0_2.pnv`.

## Architecture correction

PNCS does **not** require 36 hand-named semantic axes.

The 36-dimensional PNV state is the native computational coordinate surface. Meaning is carried by typed relations and their paths. A KAKU is therefore defined first as a minimal reusable relational operation; its 36D vector is a PhaseNav realization/binding, not the source of semantic authority.

This gives the order:

    mathematical relation
      -> KAKU operator
      -> radical composition
      -> definition path
      -> PNV 36D realization
      -> executable route

rather than:

    invented axis names -> vector -> guessed meaning

## TIR seed

The first TIR path is:

    BINARY_DISTINCTION
      -> INFORMATION_UNIT (ln 2)
      -> PHASE / HOLONOMY NORMALIZATION
      -> KAPPA = ln(2)/(24*pi)
      -> RELATIONAL_ACTION

This is used as a relational construction seed, not as a claim that every semantic relation is physically identical to the current Metatime model.

## Secret-of-a-Half seed

The first SOH path is:

    COMPLEMENT: sigma -> 1-sigma
      -> FIXED CONDITION: sigma = 1-sigma
      -> HALF: 1/2

and independently:

    BOUNDARY: (0,1)
      -> OMEGA(s)=s/(1-s)
      -> RECIPROCAL INVERSION: u -> 1/u
      -> SELF-DUAL CONDITION: |Omega|=1
      -> IMBALANCE: log|Omega|
      -> DEFECT: (log|Omega|)^2

The exact geometric identities are preserved separately from the open RH bridge.
